## 1. Создание и оформление бота у @BotFather

Все официальные боты Telegram создаются через главного системного бота [@BotFather](https://t.me/BotFather).

### Шаг 1.1. Регистрация нового бота
1. Откройте Telegram и в строке поиска найдите **`@BotFather`** (с синей галочкой верификации).
2. Нажмите **Start** и отправьте команду:
   ```text
   /newbot
   ```
3. **Имя бота (Name):** введите отображаемое имя (например, `AdmitRoute | Помощник поступления`).
4. **Юзернейм бота (Username):** введите уникальный юзернейм, оканчивающийся на `bot` (например, `admitroute_kz_bot` или `admitroute_notify_bot`).
5. **Получение токена:** @BotFather поздравит вас и выдаст секретный токен доступа вида:
   ```text
   7123456789:AAFlkjw9e8u23rjhdsf9823h_sdkjfhsdf
   ```
   > ⚠️ **КРИТИЧЕСКИ ВАЖНО:** Никогда не отправляйте этот токен в публичные чаты и не коммитьте в Git! Сохраните его в надёжном месте.

### Шаг 1.2. Оформление бота
В диалоге с `@BotFather`:
- `/setdescription` — выберите вашего бота и укажите текст приветствия, который видят пользователи до нажатия Start:
  ```text
  🎓 Официальный бот платформы AdmitRoute.kz. 
  Персональные напоминания о дедлайнах поступления, контроль статуса документов и еженедельный дайджест задач!
  ```
- `/setabouttext` — короткое описание в профиле бота:
  ```text
  Напоминания о дедлайнах и сопровождение поступления от AdmitRoute.kz
  ```
- `/setuserpic` — отправьте логотип или аватарку бота (квадратное изображение).
- `/setcommands` — настройте меню быстрых команд, отправив следующий список:
  ```text
  deadlines - Ближайшие дедлайны дорожной карты
  status - Процент готовности и стрик активности
  help - Справка и полезные контакты
  stop - Отключить уведомления
  ```

## 2. Выбор архитектуры бесплатного хостинга (Webhook vs Long Polling)

| Параметр | Режим Webhook (Реализован в AdmitRoute) | Режим Long Polling |
|---|---|---|
| **Принцип работы** | Telegram сам отправляет HTTPS POST-запрос на ваш URL при появлении нового сообщения | Приложение постоянно висит в бесконечном цикле `while(true)` и опрашивает серверы Telegram |
| **Хостинг на Vercel Serverless** | ✅ **Идеально совместим** (функция просыпается за 50 мс, отвечает за 200 мс и засыпает) | ❌ **Не работает** (Vercel Serverless принудительно завершает процессы по таймауту 10–15 сек) |
| **Потребление ресурсов** | 0 ресурсов в режиме простоя. Не расходует память и CPU. | Требует круглосуточно работающий сервер (VPS, Docker, PM2) |
| **Стоимость** | **0$ (100% бесплатно на Vercel Hobby)** | Требует отдельный VPS (от 5$/мес) или сторонний PaaS |

### Наш выбор:
Мы используем **Vercel Serverless Webhook (`/api/telegram/webhook`)**:
- Единый проект и репозиторий: фронтенд и бэкенд бота живут вместе.
- Никаких дополнительных серверов, Docker-контейнеров или виртуальных машин.
- Бесплатный план Vercel предоставляет **100 000 вызовов функций в день**, чего хватает на тысячи активных абитуриентов.

## 3. Настройка переменных окружения в Vercel

Чтобы бэкенд знал токен бота и проверял подлинность запросов Telegram:

1. Откройте панель управления [Vercel Dashboard](https://vercel.com/dashboard).
2. Выберите ваш проект **AdmitRoute**.
3. Перейдите в **Settings** → **Environment Variables**.
4. Добавьте 3 обязательные переменные:

| Переменная | Значение | Для каких сред (Environments) |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен, полученный от `@BotFather` (например, `7123456789:AAFlkj...`) | Production, Preview, Development |
| `TELEGRAM_BOT_USERNAME` | Юзернейм бота без `@` (например, `admitroute_kz_bot`) | Production, Preview, Development |
| `TELEGRAM_WEBHOOK_SECRET` | Случайная секретная строка из 32+ символов (например, `admitroute_tg_secret_token_98765xyz`) | Production, Preview, Development |
| `CRON_SECRET` | Случайная строка для защиты фоновых напоминаний (например, `admitroute_cron_secret_2026`) | Production, Preview, Development |

> 💡 **Разница сред:**
> - **Production:** применяется к вашему основному домену (`admitroute.kz` или `admitroute.vercel.app`).
> - **Preview:** для автоматических превью-веток Pull Request.
> - **Development:** для локальной разработки через `vercel dev`.

После добавления переменных выполните **Redeploy** последнего коммита в Vercel (**Deployments** → **•••** → **Redeploy**).

## 4. Привязка Webhook к Telegram Bot API

Telegram должен знать, куда отправлять входящие сообщения. Для этого вызывается метод `setWebhook`.

### Точная curl-команда (выполните в терминале):
Замените `<YOUR_BOT_TOKEN>`, `<YOUR_DOMAIN>` и `<YOUR_SECRET>` на ваши реальные значения:

```bash
curl -F "url=https://<YOUR_DOMAIN>/api/telegram/webhook" \
     -F "secret_token=<YOUR_TELEGRAM_WEBHOOK_SECRET>" \
     -F "allowed_updates=[\"message\",\"callback_query\"]" \
     https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook
```

#### Пример реальной команды:
```bash
curl -F "url=https://admitroute.vercel.app/api/telegram/webhook" \
     -F "secret_token=admitroute_tg_secret_token_98765xyz" \
     -F "allowed_updates=[\"message\",\"callback_query\"]" \
     https://api.telegram.org/bot7123456789:AAFlkjw9e8u23rjhdsf9823h_sdkjfhsdf/setWebhook
```

#### Ожидаемый ответ:
```json
{
  "ok": true,
  "result": true,
  "description": "Webhook was set"
}
```

### Проверка статуса вебхука (`getWebhookInfo`):
```bash
curl https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getWebhookInfo
```
В ответе вы увидите:
```json
{
  "ok": true,
  "result": {
    "url": "https://admitroute.vercel.app/api/telegram/webhook",
    "has_custom_certificate": false,
    "pending_update_count": 0,
    "max_connections": 40
  }
}
```

> ⚠️ **Что делать при смене домена:**
> Если вы привязали свой домен (например, `admitroute.kz`), просто повторите curl-запрос с новым URL. Telegram мгновенно перенаправит трафик.

## 5. Настройка бесплатного Cron для дедлайнов

Напоминания о дедлайнах за 14, 7, 3 и 1 день, а также еженедельный дайджест генерируются эндпоинтом `/api/cron/deadlines`.

### Вариант 1. Встроенный Vercel Cron (Уже настроен в `vercel.json`!)
В файле `vercel.json` прописано:
```json
"crons": [
  {
    "path": "/api/cron/deadlines",
    "schedule": "0 8 * * *"
  }
]
```
- **Лимиты Vercel Hobby:** Vercel бесплатно предоставляет **1 запуск cron-задачи в сутки на проект**.
- Расписание `0 8 * * *` запускает функцию ежедневно в **08:00 UTC** (13:00 по времени Астаны / Алматы).
- Vercel автоматически передаёт служебный заголовок `x-vercel-cron: 1`, благодаря которому запрос авторизуется сервером.

### Вариант 2. Внешний бесплатный триггер (cron-job.org)
Если вам нужны более частые запуски (например, каждые несколько часов):
1. Зарегистрируйтесь на бесплатном сервисе [cron-job.org](https://cron-job.org).
2. Нажмите **Create Cronjob**:
   - **URL:** `https://<YOUR_DOMAIN>/api/cron/deadlines`
   - **Schedule:** каждый день в 09:00 (или каждые 6 часов)
   - **Headers:** добавьте заголовок:
     - `Authorization: Bearer <ВАШ_CRON_SECRET>`
3. Сохраните. Сервис будет бесплатно дергать эндпоинт по расписанию.

## 6. Бесплатная облачная база данных (Neon PostgreSQL)

Проект использует бессерверный PostgreSQL от [Neon.tech](https://neon.tech), который идеально оптимизирован под Vercel Functions.

### Параметры Free Tier Neon:
- **0.5 ГБ хранилища** (достаточно для хранения более 50 000 профилей и сообщений).
- **Неограниченное число транзакций.**
- **Автоматический сон (Auto-suspend):** при отсутствии запросов вычисления засыпают, экономя лимиты, и просыпаются за 300 мс при обращении.

### Проверка таблиц в Neon Console:
В вашем проекте уже развёрнуты таблицы с активированным RLS:
1. `app_state` — глобальное состояние платформы и пользователей.
2. `users` — аккаунты абитуриентов.
3. `chat_threads` — сообщения Live-чата с куратором.
4. `application_trackers` — канбан-этапы подачи по вузам.
5. `referrals` — история реферальных приглашений.
6. `share_tokens` — токены доступа для родителей и менторов.
7. `telegram_links` — одноразовые коды привязки Telegram (TTL 10 мин).
8. `notification_logs` — журнал отправленных уведомлений (защита от спама и дублирования).

Строка подключения передаётся в Vercel через переменную `DATABASE_URL`.

## 7. End-to-End проверка работы (Чек-лист тестирования)

После деплоя пройдите следующие шаги для подтверждения 100% работоспособности:

- [ ] **Шаг 1. Регистрация на сайте:** откройте сайт AdmitRoute, зарегистрируйте тестового абитуриента.
- [ ] **Шаг 2. Генерация кода в Telegram:** в шапке сайта нажмите кнопку **«Бот в TG»** → в модальном окне нажмите **«Подключить Telegram-бота»**. Отобразится 8-значный код (например, `AR7X9K`).
- [ ] **Шаг 3. Переход в бота:** нажмите **«Открыть бота в Telegram»** (или перейдите по ссылке). Нажмите **Start**.
- [ ] **Шаг 4. Ответ бота:** бот должен мгновенно прислать приветственное сообщение:
  > *«🎉 Поздравляем! Аккаунт AdmitRoute успешно привязан!»*
- [ ] **Шаг 5. Проверка команд:** отправьте боту команды:
  - `/status` — бот пришлёт ваш процент выполнения Roadmap и стрик дней.
  - `/deadlines` — бот покажет ближайшие дедлайны выбранных университетов.
- [ ] **Шаг 6. Тестовый запуск Cron:** откройте в браузере или через curl:
  ```bash
  curl -H "Authorization: Bearer <CRON_SECRET>" "https://<YOUR_DOMAIN>/api/cron/deadlines?digest=true"
  ```
  Убедитесь, что в Telegram пришёл дайджест задач.

## 8. Лимиты бесплатных планов и масштабирование

| Сервис | Бесплатный лимит (Free Tier) | Когда будет исчерпан | Следующий шаг |
|---|---|---|---|
| **Vercel Serverless** | 100 000 вызовов функций/день, 100 ГБ исходящего трафика | > 5 000 активных пользователей в сутки | Vercel Pro (20$/мес) |
| **Neon PostgreSQL** | 0.5 ГБ данных, 1 проект, 1 ветка | > 50 000 абитуриентов в базе данных | Neon Launch (19$/мес) с хранилищем 10 ГБ |
| **Telegram Bot API** | До 30 сообщений в секунду суммарно, 1 сообщение в секунду в один чат | Лимит не упрётся при соблюдении нашей встроенной очереди | Бесплатно навсегда со стороны Telegram |
| **Google Gemini API** | 15 запросов в минуту (Free Tier AI Studio) | При одновременном поиске более 15 пользователей | Привязка Billing в Google Cloud (Pay-as-you-go, ~0.075$ за 1 млн токенов) |

Система AdmitRoute спроектирована с максимальной эффективностью:
- Кэширование и sliding-window троттлинг снижают нагрузку на внешние API.
- Серверные очереди предотвращают дублирование сообщений в Telegram.
- Архитектура готова к работе в боевом режиме без абонентской платы.
