## 1. Проблема и Задача

### Проблема
Поступление в вуз для абитуриента 9–11 классов и его родителей превращается в стрессовый хаос из десятков разрозненных решений: проходные баллы, языковые экзамены, дедлайны разных волн, стоимость и стипендии. Существующие платформы предлагают лишь бесконечные статические каталоги вузов или общие списки, не отвечая на ключевые вопросы: *«Куда именно мне поступать?», «Почему этот вариант подходит под мой бюджет и баллы?»* и *«Что конкретно сделать следующим шагом?»*.

### Наше решение
**AdmitRoute** — интерактивный веб-сервис с прозрачным UX/UI, который превращает анкету абитуриента в персональную образовательную стратегию:
1. **Диагностирует профиль** (сильные стороны, зоны риска, индекс готовности).
2. **Формирует персональный портфель вузов** по проверенной стратегии `Target` (основная цель), `Reach` (амбициозная цель) и `Safety` (страховочный вариант) с человеческим объяснением «почему подходит».
3. **Предоставляет сравнительный анализ** выбранных программ бок о бок.
4. **Генерирует помесячный интерактивный Roadmap** с контрольными точками и дедлайнами.
5. **Выделяет ровно одно ближайшее действие (Next Action)** с фиксацией прогресса.

## 2. Сквозной пользовательский сценарий (7 обязательных этапов)

1. **Вход**: Понятное объяснение ценности, быстрые пресеты для демонстрации сценариев в 1 клик.
2. **Профиль (Анкета)**: 3 логических шага со степпером (Класс/Статус, Направление, GPA, Языковой тест IELTS/TOEFL, ЕНТ/SAT, Бюджет, Страны, Сроки).
3. **Диагностика**: Расчет индекса академической готовности (%), резюме, сильные стороны и факторы риска.
4. **Рекомендации**: Подбор от 3 до 5 программ со статусами Target/Reach/Safety, подробными требованиями и аргументацией совпадения.
5. **Сравнение**: Интерактивная таблица для одновременного сравнения 2+ программ по всем критериям (язык, экзамены, стоимость, общежитие, дедлайны).
6. **Roadmap**: Хронологический календарь контрольных точек с возможностью отмечать выполненные шаги.
7. **Следующее действие**: Фокусный баннер ближайшего шага с чекбоксом закрытия и моментальным пересчетом прогресса.

> **Реактивность**: При нажатии «Скорректировать ответы» и изменении любого ключевого параметра (например, смена бюджета с платного на «Только 100% грант» или языка) рекомендации и дорожная карта динамически и заметно перестраиваются.

## 3. Стек технологий и Архитектура

- **Frontend Core**: React 18, TypeScript, Vite.
- **Стилизация**: Tailwind CSS (спокойная строгая палитра Slate/Neutral без неоновых эффектов).
- **Иконки**: `lucide-react` (строгие векторные SVG-иконки без использования эмодзи).
- **Хранение состояния**: `LocalStorage` (сохранение профиля, прогресса чеклиста и сессии).
- **AI & Scoring Engine**: Детерминированная скоринговая модель соответствия (`src/utils/engine.ts`), сопоставляющая квартили GPA, языковые пороги, доступность стипендий и дедлайны.

## 4. Инструкция по локальному запуску

```bash
# 1. Клонировать репозиторий
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd admitroute

# 2. Установить зависимости
npm install

# 3. Запустить режим разработки
npm run dev

# 4. Собрать продакшн-версию
npm run build
npm run preview
```

## 5. Тестовый сценарий для жюри

Для быстрой проверки жюри на главной странице доступны 3 готовых пресета:
1. **Сценарий 1 (IT в Казахстане, 11 класс)**: GPA 4.7, IELTS 6.5, ЕНТ 115, бюджет: 100% грант. Система рекомендует КБТУ и AITU (Target), Назарбаев Университет (Reach) и МУИТ (Safety), формируя план сдачи грантового ЕНТ.
2. **Сценарий 2 (CS в Европе, 10 класс)**: GPA 4.9, IELTS 7.5, SAT 1420. Система строит маршрут в TUM и Politecnico di Milano с упором на стипендию DSU и дедлайны стандартизированных тестов.
3. **Сценарий 3 (Инженерия, бюджет «Только грант»)**: GPA 4.2, ЕНТ 98. Демонстрирует честное предупреждение о необходимости фокуса на Satbayev University и региональных инженерных квотах.
